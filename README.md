## Getting Started

First, run the development server:

```bash
npm install
then
npm run build
then
npm run start
```

Open [http://localhost:3000](http://localhost:3000) with your browser to see the result.
enter any number and go to doc page 

open devtools>application>service workers check offline box  to simulate offline mode
